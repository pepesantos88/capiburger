# CapiBürger

Mobile-first study app demo. The questions and answer choices are in German; the interface, explanations and Capi’s reactions are in English. It includes a daily streak, favourites, categories, a 33-question mock exam, an opening reminder and Capi the capybara.

## Ejecutar

Open `index.html` in a browser or publish this folder as a static site on Netlify.

## Next integration

`questions.js` contains the data format for replacing the sample questions with the complete official BAMF catalogue: 300 general questions and the 10 Berlin questions.
